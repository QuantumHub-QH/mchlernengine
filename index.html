Akun
Setup Roblox
API key disimpan terenkripsi dan hanya dipakai untuk mengunggah asset milikmu.

 
Panduan: cara dapat API key & Target ID
  
    
   
  1. Login Roblox, buka create.roblox.com/dashboard/credentials (Creator Hub → Open Cloud → API Keys).
    2. 
   
  2. Klik Create API Key, beri nama bebas (mis. SpooferAsset).
    3. 
   
  3. Di Access Permissions klik Add API System, pilih Assets. Tambahkan operasi Read dan Write (keduanya dicentang). Untuk Upload audio & decal, izin ini wajib.
    4. 
   
  4. Di Accepted IP Addresses isi IP VPS-mu, atau 0.0.0.0/0 agar semua IP diizinkan. Atur Expiration sesuai kebutuhan.
    5. 
   
  5. Klik Save & Generate Key, lalu salin key-nya sekarang (hanya muncul sekali) dan tempel di kolom API key di bawah.
    6. 
   
  6. Target ID · User: angka di URL profilmu, roblox.com/users/ANGKA/profile. API key harus dibuat oleh akun yang sama dengan Target ID ini.
    7. 
   
  7. Target ID · Group: angka di URL grup, roblox.com/communities/ANGKA/…. Pilih tipe Group; akun pembuat key harus punya izin kelola asset di grup itu.
    8. 
   
  8. Klik Simpan. Key disimpan terenkripsi dan tidak ditampilkan lagi.
    9. 
  

  
Catatan: Roblox bisa meminta verifikasi akun untuk upload audio dan menerapkan batas upload per bulan. Tiap upload sukses dihitung 1x jatah harian (paket gratis).
